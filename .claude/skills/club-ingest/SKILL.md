# club-ingest: текст клуба → данные сайта

Источник правды по полям — `data/README.md`. Читай его перед каждой правкой и не
пересказывай поля по памяти. Образцы: `data/club.example.yaml`,
`data/glossary.example.yaml`.

Окружение для всех команд: `PYYAML_FORCE_LIBYAML=0 PYTHONUTF8=1`, Python —
`.venv/Scripts/python`.

## 1. Определи, что прислали

| Вход | Признаки | Что меняется |
| --- | --- | --- |
| Анонс | дата и время в будущем, «разбираем главы…», афиша | встреча: `date`, `book`, `chapters` (planned), `announce`, `format`, `host`, `images.poster` |
| Итоги | «разобрали», «спорили», цитата вечера, карточка итогов | встреча: `chapters` (closed/carried), `outcome`, `topics`, `images.recap` |
| Текст о главах | пересказ глав без даты встречи | спроси, к какой встрече он относится; без ответа — только словарь |
| Конспект главы | один файл главы книги | словарь: новые понятия и `chapters` у существующих |

Встречу ищи по дате и книге среди `meetings` в `data/club.yaml`. Нет встречи
и нет даты — не создавай её: спроси дату. Конспект сопоставь с книгой (`books`)
и номером главы по оглавлению.

## 2. Встреча в `data/club.yaml`

- `id` новой встречи — `m-ГГГГ-ММ-ДД`, `date` — `ГГГГ-ММ-ДД`.
- `chapters` — номера по оглавлению книги в `books`, а не по нумерации поста:
  сверяй название главы с `chapters[].title`. Расходится — спроси.
- Анонс: глава без `outcome` = planned. Итоги: `closed` — закрыли, `carried` —
  начали и не закончили.
- `outcome`: короткая выжимка (`agreed`, `argued`, `taken`, `quote`) и полная
  форма (`lead`, `by_chapter`, `debates`, `aside`, `verdict`) — как в посте, по
  порядку поста. Номера глав в `by_chapter` проверяй по книге встречи.
- `topics` — понятия встречи, названиями из словаря (`name` или `aliases`).
- `host` — ведущий, если назван.
- Строку с «двоеточие + пробел» бери в кавычки (см. «Ловушка» в README).

### Имена и факты

- Имя участника допустимо только в `host`. Во всех текстах итогов убери имена,
  ники и узнаваемые описания: «одни считают…», «прозвучал контраргумент…».
- Ничего не досочиняй: спора, цитаты, вывода или номера главы, которых нет в
  источнике, в данных быть не должно. Нет части — не заполняй поле и скажи
  пользователю, чего не хватило.

### Картинки

Афиша — `images.poster`, карточка итогов — `images.recap`; у обеих обязательны
`src` и `alt`. Файл — `app/web/static/meetings/<id встречи>-poster.jpg` или
`-recap.jpg`, JPEG 1080×1350 (4:5) не больше 300 КБ. `alt` пересказывает текст на
картинке, без имён участников.

Pillow в проекте не установлен — ставь его во временную папку, не в `.venv`:

```bash
.venv/Scripts/python -m pip install --target "$TMP/pil" pillow
PYTHONPATH="$TMP/pil" .venv/Scripts/python - <<'PY'
from PIL import Image
src, dst = "ИСХОДНИК.png", "app/web/static/meetings/m-ГГГГ-ММ-ДД-poster.jpg"
image = Image.open(src).convert("RGB").resize((1080, 1350), Image.LANCZOS)
for quality in (85, 80, 75, 70, 65):
    image.save(dst, "JPEG", quality=quality, optimize=True, progressive=True)
    if __import__("os").path.getsize(dst) <= 300_000:
        break
PY
```

Исходник не 4:5 — не растягивай: спроси, как кадрировать.

## 3. Понятия в `data/glossary.yaml`

1. Выпиши понятия из текста: термины, законы, паттерны, аббревиатуры.
2. Сверь каждое со словарём по `name` и `aliases` без учёта регистра и «ё».
3. Есть совпадение — в `topics` встречи пиши название как в посте; если оно
   отличается от `name`, проверь, что оно есть в `aliases`.
4. Почти совпадает (другая форма, английское название, сокращение) — предложи
   синоним к существующему понятию, а не новое понятие.
5. Нового понятия нет — предложи карточку: `id` (латиница, дефис),
   `name`, `summary` в 1–3 фразы простым русским **из конспекта или статьи**
   (репозиторий конспектов: `C:\Users\Shvechka\Desktop\Project\pet\club_book_conspects`,
   `books/*/chapters/*.md` и `topics/*.md` — ищи grep'ом), `chapters` — только
   главы, где понятие правда разобрано, `article` — точный адрес файла
   `topics/` на GitHub, закодированный как `notes_url` в `club.yaml`,
   `related` — существующие id.
6. В конспектах понятия нет — напиши нейтральное общее определение, поставь
   над карточкой комментарий `# Без источника в конспектах` и скажи об этом.

Списка встреч по понятию в словаре нет и не заводи его.

## 4. Покажи план и жди

До записи покажи коротко:

- какая встреча (новая или найденная), какие поля меняются, главы с номерами;
- новые понятия и синонимы — по строке на каждое;
- что убрано (имена) и чего в источнике не нашлось.

Пиши в файлы только после явного «да». Правки пользователя внеси и покажи
план ещё раз, если изменилось что-то кроме формулировок.

## 5. После записи

```bash
PYYAML_FORCE_LIBYAML=0 PYTHONUTF8=1 .venv/Scripts/python -c "from app.data.loader import load_club_data; d = load_club_data('data/club.yaml'); print(len(d.meetings), 'встреч,', len(d.glossary), 'понятий')"
PYYAML_FORCE_LIBYAML=0 PYTHONUTF8=1 .venv/Scripts/python -m pytest -q
```

`DataError` называет место ошибки — исправь и запусти снова. Тест
`test_every_meeting_topic_of_the_working_data_has_a_term` падает, если у темы
встречи нет понятия: добавь понятие или синоним. Доложи результат загрузки и
число пройденных тестов.

Напомни: сайт в Docker видит новые данные после `docker compose restart web`
(пересборка не нужна, `data/` смонтирована).
