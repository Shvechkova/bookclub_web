# Spec Delta

## ADDED Requirements

### Requirement: Год основания и манифест клуба задаются данными

Клуб SHALL хранить год основания числом и фразу-манифест строкой. Оба поля
необязательны. Год MUST NOT выводиться разбором текста «О клубе».

#### Scenario: Поля заданы

- **WHEN** в данных клуба заданы `since: 2023` и манифест
- **THEN** модель отдаёт год 2023 и манифест как есть

#### Scenario: Поля не заданы

- **WHEN** год и манифест в данных отсутствуют
- **THEN** модель отдаёт пустые значения, и это не ошибка загрузки

#### Scenario: Год не числом

- **WHEN** год основания задан строкой «давно»
- **THEN** загрузка данных падает с понятной ошибкой

### Requirement: У книги есть короткое название

Книга SHALL иметь необязательное короткое название для подписей, где полное не
помещается. Если короткое не задано, SHALL использоваться полное. Встреча без
книжной части SHALL подписываться собственным названием.

#### Scenario: Короткое название задано

- **WHEN** у книги «Высоконагруженные приложения, 2-е издание» задано короткое «Высоконагруженные приложения»
- **THEN** подпись встречи по этой книге — «Высоконагруженные приложения»

#### Scenario: Короткое название не задано

- **WHEN** у книги короткого названия нет
- **THEN** подпись берёт полное название книги

### Requirement: Выборки для главной вычисляются из встреч

Система SHALL вычислять для главной свежие понятия, свежие споры и встречи с
картинками из данных встреч и SHALL NOT хранить их отдельно. Учитываются только
прошедшие встречи, кроме ближайшей встречи в выборке картинок.

#### Scenario: Свежие понятия

- **WHEN** у прошедших встреч есть темы, а у будущей встречи — своя тема
- **THEN** выборка понятий идёт от последней прошедшей встречи, без повторов, и без темы будущей

#### Scenario: Встречи с картинками

- **WHEN** у прошедшей встречи есть карточка итогов, у ближайшей — афиша, у третьей картинок нет
- **THEN** выборка содержит прошедшую встречу с карточкой итогов и ближайшую с афишей
- **AND** встречи без картинок в выборке нет
- **AND** выбранной по умолчанию считается последняя прошедшая встреча с картинкой
