# Spec Delta

## ADDED Requirements

### Requirement: Счётчик посещений Яндекс.Метрики

Если задана переменная `YANDEX_METRIKA_ID` с номером счётчика, каждая страница
сайта, включая страницу «не найдено», SHALL нести код счётчика Яндекс.Метрики
с этим номером и запасную картинку-пиксель в `<noscript>`. Без переменной, с
пустым значением или со значением не из одних цифр кода счётчика SHALL NOT
быть, и страницы SHALL NOT обращаться к `mc.yandex.ru`.

#### Scenario: Номер счётчика задан

- **WHEN** сайт собран с `YANDEX_METRIKA_ID=114153922`
- **THEN** на каждой странице есть скрипт, который грузит `https://mc.yandex.ru/metrika/tag.js?id=114153922` и запускает счётчик `114153922`
- **AND** в `<noscript>` стоит картинка `https://mc.yandex.ru/watch/114153922`

#### Scenario: Номер счётчика не задан

- **WHEN** сайт собран без `YANDEX_METRIKA_ID`
- **THEN** на страницах нет ни одного упоминания `mc.yandex.ru`

#### Scenario: В переменной не номер

- **WHEN** сайт собран с `YANDEX_METRIKA_ID=abc"` или со значением из пробелов
- **THEN** кода счётчика на страницах нет

#### Scenario: Страница «не найдено»

- **WHEN** сайт выгружен с заданным номером счётчика
- **THEN** код счётчика есть и в `404.html`
