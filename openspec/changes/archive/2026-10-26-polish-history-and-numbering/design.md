# Design

## Context

Номер встречи, первая встреча по книге и лента считаются в ядре
(`ClubView.numbered_meetings`, `is_first_of_book`, `history`), шаблоны только
выводят. Печать, билет и наклейка — оформление в `_macros.html`, `base.html` и
`style.css`. Мотивация — в proposal.md.

## Goals / Non-Goals

**Goals:**
- Один номер встречи на весь сайт: страница, лента, наклейка, заголовок
  страницы и описание для поиска берут его из одного места.
- Печать и билет не мешают читать: состояние книги остаётся словом в тексте.

**Non-Goals:**
- Новый блок понятий. Его вернут отдельным изменением; понятия в заставке
  главной остаются как были.
- Перенос ленты на адрес `/shelf`.

## Decisions

### Номер считается по книге, ряд без книги — отдельно

Счётчик ведётся по `book_id`: у каждой книги свой ряд с единицы, у встреч без
книжной части (`book_id` пуст) — свой общий ряд. Альтернатива — встречам без
книги номера не давать. Отклонено: у страницы такой встречи заголовок
«Встреча #N», и на него опираются описание для поиска и карточка пересылки.

Номер по книге неоднозначен вне книги: «#2» есть у каждой книги. Поэтому там,
где встречи разных книг стоят рядом без заголовка книги, их подписывают датой.
Сейчас такое место было одно, каталог понятий, и он убран.

### Корешок билета — число назначенных встреч

N в «встреча №N» — `len(meetings_of(book))`, то есть номер последней
назначенной встречи по книге, включая предстоящую. Альтернатива — номер
последней прошедшей. Отклонено: билет выдают на встречу, на которую идут.

### Печать — один символ SVG на страницу

Символ `#stamp` описан один раз в `base.html`, обложка ссылается на него через
`<use>`. Название клуба по кругу берётся из данных. Печать `aria-hidden`:
состояние «закрыта» уже сказано словами рядом с обложкой. В сетке «Уже
прочитали» печать стоит внутри обложки с запасом на поворот; в ленте и на
странице книги справа есть поле, и печать выходит за угол обложки. Горизонтальной
прокрутки на 360 точках нет ни там, ни там.

### «История» переименована в «Полку», адрес `/history` оставлен

Сайт ещё не выложен, но адрес — это ссылки в тестах, экспорте, карте сайта и
внутреннее имя раздела `section="history"` для подсветки. Меняется только то,
что видит посетитель: пункт шапки, `<h1>` и `<title>`. Меньше движущихся
частей — меньше поломок; адрес можно сменить отдельно, когда понадобится.

Прежняя «Полка» убрана вместе с маршрутами, шаблонами, адресами экспорта и
описаниями для поиска. `ClubView.topics()` остаётся: на нём стоит выборка
понятий для заставки главной.

### «О клубе»: карточки — данные, а не разметка

Факты и порядок встречи — списки карточек `{label, text}` в данных клуба, одна
модель `Card` на оба списка. Альтернатива — вписать карточки в шаблон.
Отклонено: это голос клуба, его правят в данных, как манифест. Карточки
необязательны: без них страница показывает прежние абзацы `about` и список
`routine`, чтобы образец данных без новых полей не давал пустых мест. Карточка
без одного из полей отвергается при загрузке.

Кабан — `logo-mark.png`, отражённый CSS-ом, `alt=""`. Он стоит в правой части
колонки 860 точек и выходит за неё не дальше 120 точек и не дальше края окна:
отступ считается через `max()` от ширины окна. На узком экране он обтекается
лидом справа.

Перечень форматов убран только со страницы: `ClubView.formats()` и его тесты
остаются, блок может вернуться в другом месте. В «Куда писать» сначала чат
площадки: ветка клуба открывается только его участникам. Чат клуба («Чат читальни») стоит
последним, контурной кнопкой с пометкой «— после первого посещения»: это путь
для того, кто уже пришёл.

## Risks / Trade-offs

- [Адрес `/history` у раздела «Полка» путает того, кто читает адрес] → цена
  небольшая, адрес меняется отдельным изменением с переадресацией.
- [Номер «#2» повторяется у разных книг] → рядом с номером всегда стоит книга
  или дата; места без них подписываются датой.
