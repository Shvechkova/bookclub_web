# Spec Delta

## ADDED Requirements

### Requirement: Ключевые действия посетителя отмечаются целями счётчика

Когда на странице есть счётчик Яндекс.Метрики, клик по ссылке «В календарь», по ссылке на чат клуба, по ссылке на конспект главы или книги и по кнопке «Играть» SHALL отправлять в счётчик цель с идентификатором `calendar`, `chat`, `notes` и `warmup` соответственно. Ссылка SHALL вести туда же, куда раньше, и открываться так же. Без счётчика страница SHALL NOT содержать кода отправки целей.

#### Scenario: Клик по «В календарь» при включённом счётчике

- **WHEN** на странице предстоящей встречи со счётчиком посетитель нажимает «В календарь»
- **THEN** в счётчик уходит цель `calendar`
- **AND** открывается ссылка календаря

#### Scenario: Ссылки помечены своими целями

- **WHEN** на странице есть ссылка на чат клуба, ссылка на конспект и кнопка «Играть»
- **THEN** ссылка на чат помечена целью `chat`, ссылка на конспект — `notes`, кнопка — `warmup`

#### Scenario: Счётчик не задан

- **WHEN** сайт собран без номера счётчика
- **THEN** на страницах нет кода отправки целей
- **AND** ссылки работают как обычные ссылки
