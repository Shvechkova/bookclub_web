# Proposal

## Why

В словаре клуба около двухсот понятий, и найти нужное можно только листая
страницу или угадывая букву в указателе. Человек приходит со словом из чата или
со встречи — «закон Конвея», «DDD», «Conway's law» — и не знает, под какой
буквой и на каком языке оно записано. Сайт статический (GitHub Pages), сервера
нет, поэтому искать нужно прямо в браузере, по уже загруженной странице.

## What Changes

- Поле «Поиск по словарю» вверху страницы «Словарь»: фильтрует понятия по мере
  ввода по названию, синонимам и определению, без учёта регистра, «ё» и
  знаков препинания; все слова запроса должны найтись.
- Порядок выдачи: сначала понятия, чьё название или синоним начинается с
  запроса, потом те, где запрос внутри названия или синонима, потом найденные
  только в определении; внутри — по алфавиту.
- Счётчик «Найдено: N» для экранных чтецов и глаз, подсветка совпадений в
  названии и синонимах, пустое состояние с подсказкой.
- Запрос живёт в адресе (`?q=`): поиском можно поделиться. Esc очищает поле,
  «/» ставит в него фокус. Переход по якорю сбрасывает запрос, чтобы понятие
  было видно.
- Текст для поиска отдаётся сервером в атрибутах карточек, второго запроса нет.
  Без скриптов поля нет, словарь показывается целиком, как сейчас.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `club-glossary`: страница «Словарь» получает поиск по понятиям.

## Impact

- `app/web/search.py` (нормализация текста для поиска), фильтры в
  `app/web/app.py`.
- Шаблон `app/web/templates/glossary.html` (тело страницы), новый скрипт
  `app/web/static/glossary-search.js`, раздел стилей в конце `style.css`.
- Тесты: `tests/test_glossary_search.py`, `tests/test_glossary_search_layout.py`,
  новые проверки в конце `tests/test_layout.py`; в `tests/test_pages_glossary.py`
  поиск карточки терпит новые атрибуты.
