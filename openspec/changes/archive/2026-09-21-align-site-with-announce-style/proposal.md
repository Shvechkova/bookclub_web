## Why

Комплект анонса первой встречи по Бруксу задал клубу узнаваемый набор приёмов: рукописная подпись автора маджентой, наклейка «начинаем новую книгу · встреча №1» поверх шапки и бегущие строки, которые вместо общих слов объясняют формат — «не лекция, не доклад», «не прочитал — всё равно приходи». Человек, который пришёл на сайт по ссылке из поста, видит другую страницу: подпись автора — серая моноширинная строка, наклейки нет, бегущие строки говорят «КОД · КНИГИ · СПОРЫ · КОФЕ · ГЛАВЫ» — набор слов, из которого ничего не следует.

Обложки тоже есть не у всех: у четырёх книг из пяти на их месте плашка, хотя картинки трёх прочитанных книг лежат в репозитории конспектов — на них ссылаются README самих конспектов.

## What Changes

- Имя автора книги набирается рукописным начертанием маджентой — на странице книги и в блоке читаемой книги.
- У первой встречи по книге появляется наклейка «начинаем новую книгу» с номером встречи: в разделе «Сейчас» и на странице встречи.
- Бегущие строки берут тексты из анонса: верхняя перечисляет, что происходит на встрече, нижняя снимает страх прийти неподготовленным.
- Обложки появляются у «Фундаментального подхода», «Изучаем DDD» и «Создания микросервисов»; у «Высоконагруженных приложений» картинки пока нет — книга выходит 15 октября, плашка остаётся.

## Capabilities

### New Capabilities

Новых возможностей нет.

### Modified Capabilities

- `club-site`: визуальная система получает рукописный акцент на имени автора и наклейку первой встречи по книге.
- `club-model`: модель отвечает на вопрос, первая ли это встреча по своей книге.

## Impact

- Данные: `data/club.yaml` — тексты бегущих строк и обложки трёх книг.
- Статика: шрифт Caveat в списке подключаемых, файл обложки в `app/web/static/covers/`.
- Ядро: `app/core/view.py` — признак первой встречи по книге.
- Шаблоны и стили: `now.html`, `meeting.html`, `book.html`, `style.css`.
- Тесты: `tests/test_brand.py`, `tests/test_pages_meeting.py`, `tests/test_pages_cover.py`, `tests/test_core_schedule.py`.
