## ADDED Requirements

### Requirement: Первая встреча по книге отличима от остальных

Модель SHALL отвечать, является ли встреча первой по своей книге: первой считается встреча с самой ранней датой среди встреч этой книги. Встреча без книжной части первой не бывает.

#### Scenario: Первая встреча новой книги

- **WHEN** по книге назначены встречи 23 сентября, 7 октября и 21 октября
- **THEN** первой по книге считается встреча 23 сентября
- **AND** встречи 7 и 21 октября первыми не считаются

#### Scenario: Встреча без книжной части

- **WHEN** у встречи нет книжной части
- **THEN** она не считается первой по книге

#### Scenario: Встреча добавлена раньше прежней первой

- **WHEN** в данные добавлена встреча по той же книге с более ранней датой
- **THEN** первой по книге становится она, а прежняя первой быть перестаёт
